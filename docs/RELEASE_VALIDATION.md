## 学習と保存

tests/core.test.tsはNode SQLiteで実際のSQLとトランザクションを実行した。記録OFFでunknown・ヒント・解説を扱ってもSQL変更数が増えないこと、記録ONの履歴がDB再開後も残ること、unknown後の正答が最初の結果を上書きしないことを確認した。

パック更新やバックアップ復元の検証失敗は既存DBを保持する。前提の循環、存在しない正解、未対応capabilityを拒否する。全角数値・名称/式の別表記を扱い、不正な数値は未提出とする。同日反復や、異なる問題での誤答だけで定着を断定しない。別の数学パックも同じ採点・履歴・学習処理を使う。代表的化学計算は教材生成とは別の式で照合した。

これはexpo-sqliteの実機実行を確認したものではない。

## 画面操作の8シナリオ

1. 同梱した114知識・185問がホームから利用できる。
2. 記録OFFでunknown、ヒント、解説、終了を操作しても保存内容がバイト単位で同じ。
3. 記録ONでunknown→ヒント→正答しても最初のunknownが残り、架空の誤解タグが付かない。
4. ページ再読み込みで記録ONの履歴が残る。
5. 読み込み後にネットワークを切っても問題・解説・採点を使える。
6. 反応マップの条件を隠す/表示する。
7. ファイル選択から数学パックを追加し、同じ画面で解答を採点する。
8. バックアップをファイルへ書き出し、別教科/フィルターの状態から復元して履歴と学習可能な状態を取り戻す。

Web版はlocalStorage。日本語フォントのない検証ホストにはテスト時だけNoto Sans JPを注入した。Androidは端末フォントを使い、テスト用フォントをAPKへ追加していない。画面PNGはartifactsにある。

## 配布APK

kanahebi-study-0.1.0-arm64.apkはrelease構成で、プログラムを開発サーバーから読むdebug APKではない。Hermesプログラム、全収録知識/問題ID、SQLiteネイティブライブラリを内蔵する。アカウントや初回教材ダウンロードを実装していない。Android INTERNET権限を宣言せず、Expo updatesは無効、allowBackup=false。

署名は試用向けのAndroid Debug証明書。ストア配布用秘密鍵は作成・公開していない。実機実行済みやストア公開済みとは扱わない。

サイズ、SHA-256、SDK、ABI、権限と内蔵データの検査結果は[android-apk-validation.json](../artifacts/android-apk-validation.json)にある。

## 教材とモデルの限界

広い導入範囲と基本演習の初版。第三者の化学校閲、難関大学向けの十分な問題密度、長期の学習効果評価は未実施。化学式は文字・縮合構造式で、分子編集や自由記述証明の意味判定はない。習熟度は暫定ルールで、校正された正答確率や合格可能性ではない。

## ビルド環境の修復

公式Command-Line Tools 15859902のSHA-256を公式値と照合した。Build Tools 36.0.0の欠損は再インストールし、Gradleの生成済みtransformキャッシュの不整合は該当キャッシュ再生成で解消した。実行環境のHTTPSプロキシポートがコマンドごとに変わるため、同じビルドプロセスで環境変数からGradleへ設定を与えた。この設定やプロキシをアプリへ同梱していない。

通常環境ではREADMEの手順を使う。SDK、node_modules、ネイティブ生成物、秘密鍵、テスト用解答データはソース管理対象ではない。
