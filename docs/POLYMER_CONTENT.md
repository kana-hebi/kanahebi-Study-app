# 高分子教材 v0.2.0

作成日: 2026-10-06 JST。現在の進捗はSTATUS.md。この文書は収録範囲・著作方針・再生成方法を記録する。

## 収録した量と使い方

40教材を「短い要点だけ」から、到達目標、詳しい説明、図や比較表、解き方を開ける例題、関連教材、出典を持つ教材へ改訂した。図は44点（教材29・演習15）、例題40問、追加演習180問。追加演習は選択89・名称/式35・計算56、難易度は基礎32・標準91・応用57。各教材に新しい演習を少なくとも4問対応させ、うち20問は総合問題として作成した。

従来の対応問題52問も残し、今回の40知識で取り組める問題は232問。これらは解説付き例題40問とは別に数える。パック全体は13単元、123知識、365問、27反応関係。既存114知識・185問のIDと採点契約を保ち、9知識と180問を追加した。

ホーム「高分子の教材を読む」は繰返し単位から始める。各教材の「つなげて読む」から順に読める。「高分子の演習を選ぶ」は40知識全体を選び、糖・タンパク質・繊維など既存の複数単元を含む。形式・単元・難易度・知識でさらに絞れる。資料集や自由学習は詳しい本文、表、例題も検索できる。図と例題は端末内にあり、図は拡大できる。

## 学習の順序と範囲

| まとまり | 教材 | 身につける考え方 |
|---|---|---|
| 単位と付加重合 | 基礎、付加重合、PE、PVC、PS、PTFE、PMMA | 単量体から主鎖/側基へ写す。C=Cの変化、原子価、側基の位置を読む。PP・PAN・PVAcも比較する。 |
| 縮合と鎖の計算 | 縮合重合、PET、ナイロン66、ナイロン6、重合度、有限鎖 | 繰返し単位と有限鎖を分ける。官能基の連結、脱離分子、末端、原料比、鎖数・環状の条件を数える。 |
| 性質と設計 | フェノール樹脂、尿素樹脂、熱可塑/熱硬化、構造と物性、ゴム、共重合 | 付加/縮合と熱的分類を分け、架橋・分岐・配向・結晶・水素結合から性質を説明する。 |
| 官能基の逆算 | イオン交換、単量体の復元、加水分解、生分解性 | 電荷とサイト数を保存する。切断箇所を主鎖/側基から判断する。塩基性の塩、生分解と原料由来の分類を区別する。 |
| 糖とセルロース | デンプン、ヨウ素呈色、セルロース、置換度 | α/βと1,4/1,6、加水分解で増える水の質量、残基OH3個、置換質量の差を使う。 |
| 繊維 | レーヨン、アセテート、天然繊維、ビニロン、PVA、アクリル | 最終成分と製造分類を分ける。PVAcのけん化、PVAのアセタール化、PANのNを質量計算へつなぐ。 |
| 生体高分子 | ペプチド、配列順序、ビウレット、検出反応、変性、ヌクレオチド | n−1の条件、配列の方向、検出の例外、変性と加水分解、鎖内結合と塩基間水素結合を区別する。 |
| 発展 | 平均分子量 | 数平均・質量平均・分散度を定義付きで扱う。大学の発展事項を高校の必須暗記に混ぜない。 |

単に材質名を尋ねる問題だけでなく、構造からの逆算、誤った説明の検討、観察の解釈、質量・原子数・官能基数の保存、複数条件の計算を含めた。全問題に2段階以上のヒントと解説を付けた。誤選択肢の説明はその選択の誤解を扱い、「わからない」に誤選択のタグを付けない既存動作を保つ。

## 代表例

- PET：単位式量192を使う近似と、酸/ジオール各n分子から1本の鎖をつくるときの水2n−1分子を比較する。ナイロンでも原料数と末端条件を与える。
- PMMA/PVA：側基のエステル切断がC−C主鎖の切断と同じではないことを、PETの加水分解と対比する。
- ビニロン：けん化とアセタール化を段階ごとに追う。OH2個につきHCHO1個であること、鎖内の環形成と鎖間架橋の違い、市販PVA繊維の多様性を明記する。
- 検出反応：芳香環なら全アミノ酸が同じように呈色する、Sを含めばどの残基も同じ試験で検出できる、という一般化を避ける。
- 総合計算：PE/PS混合物の燃焼、NBRのN分析、有限鎖と不等量原料、末端COOHから数平均、置換度と回収率、陽/陰イオン交換を組み合わせる。

## 再生成と検証

`npm run author:content`が基礎パックを生成し、`scripts/enrich-polymers.py`を経由して`content/authoring/polymer-{diagrams,lessons,exercises}.py`の著作データを取り込む。完成JSONを読むアプリはPythonを実行しない。

`npm run validate:content`でcapability、図の座標/型、参照、前提関係、問題形式、ヒント/説明を検証する。`tests/polymer.test.ts`は旧114知識/185採点契約、SQL・ブラウザの更新保持、不正な図の更新拒否、検索、40教材/180問のカバレッジ、新計算56問の独立照合を確認する。図と画面の確認手順は検証記録にある。

自動照合は第三者の化学校閲ではない。数平均・質量平均やTg/Tmは発展として扱い、これだけで全大学の高分子出題に十分とは断定しない。入試問題の網羅的分析や実際の学習者による教材評価は別の確認工程である。
