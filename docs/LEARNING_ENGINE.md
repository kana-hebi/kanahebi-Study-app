# 初版の学習・保存契約

## データの責任

アプリコードはTypeScript/React Native/Expo、教材は専用JSON。教材内にHTML・評価する式・実行するJavaScriptはない。Androidでは`expo-sqlite`、ブラウザでの検証版ではlocalStorageを使う。両方とも同じRepository契約と学習エンジンを利用する。ブラウザの保存方式はAndroidのSQLite実機検証の代替ではない。

SQLite v1にはpacks、attempts、bookmarks、settingsとschema_versionsがある。習熟度・弱点・復習予定は履歴から決定的に再計算する派生状態で、教材が成績データを上書きすることはない。読み込みに失敗しても自動消去しない。

## 解答の証拠

Attemptには最初の結果`firstOutcome`と補助後の結果`finalOutcome`を分けて保存する。`unknown`、誤答、正答は別。明示的な「わからない」、解答の閲覧、回答前のヒント使用は未補助の想起が成立していない証拠となる。最初にunknownを記録したAttemptを後からcorrectへ書き換えることは禁止する。ヒント使用数や補助後の結果は同じAttemptに追記する。

誤選択に対応する誤解タグは誤選択が実際に行われた場合のみ付く。unknownの後の回答から特定の誤解を断定しない。空欄・数値欄の単位付き入力・NaN・無限大・不完全な数値は未提出として扱い、回答証拠にしない。文字列はNFKC、空白、下付き数字等を正規化するが、化学構造の同型判定は実装していない。別表記は教材のaliasesで明示する。

## 記録ON/OFF

セッション開始時に保存方針を固定する。コース・復習・診断・総合演習は記録ON。自由学習は既定ONで、開始前にOFFへ切り替えられる。OFFの場合はRepositoryの保存メソッドがデータベースへ触れる前にreturnする。セッションID・回答・結果集計はメモリ内だけにあり、終了やアプリ再起動で消える。OFF中でも明示的な教材ブックマークは保存できる。

## 初版の習熟度ルール

これは確率として校正されたモデルではなく、説明可能な暫定指標である。回答時間は履歴へ収集するが、初版では学力ペナルティに使わない。

| 証拠 | スコアへの影響 | 復習予定 |
|---|---|---|
| 無補助正答・初めての問題 | +0.26、上限0.99 | 次の日から |
| 同じ問題・別の日の無補助正答 | +0.12 | 成功した日数に応じ1/3/7/14/30日 |
| 同じ日・同じ問題の無補助正答 | +0.02 | 同日反復だけでは間隔を伸ばさない |
| 誤答・unknown・補助あり | 現スコア×0.65、補助後正答なら+0.06 | 10分後 |

未確認は履歴なし。安定はスコア0.65以上かつ無補助正答3回以上。定着は0.85以上、無補助で正答した異なる問題3個以上、異なる成功日3日以上、直近無補助正答3連続以上。誤答した問題の種類数は定着の条件に加えない。初版の問題密度では定着まで評価できない知識もある。安定・定着数を、全問題正答率や入試合格可能性とみなさない。

## コース選択

期限を過ぎた復習を優先し、次に前提確認が済んだ未確認知識を教材順に推奨する。前提確認は、対象知識で無補助正答が1回以上ありスコア0.2以上という軽い条件。習得済みを要求して先へ進めなくするものではない。前提不足の知識にもアクセスでき、説明を表示するだけでロックしない。

既習チェックは単元から3〜5問を出す。個々の回答を通常の学習証拠として使う。通過範囲の表示は一時的で、問題のない知識まで習得済みとはしない。初版の診断は適応的な単元全体の免除ではない。

## 教材パック更新

専用ファイルは`.study-pack.json`または同じ形式の`.json`。初版上限はテキスト5MB、500単元、5000知識、10000問題、2000反応。manifest、schemaVersion、capability宣言、ID重複、正解の存在、知識参照、前提グラフの循環、説明・ヒント・出典を確認してから有効化する。

同じpackIdの更新はバージョンを上げ、既存知識IDを保持する。古い版への置換や同じ版での内容変更は拒否する。旧知識を削除する更新は初版では拒否するため、削除・統合が必要になったら別途移行機能を実装する。更新は一つのトランザクションで行い、失敗時には既存教材・履歴を保持する。署名・教材の第三者校閲・PDF等の直接インポートは実装していない。

## バックアップ

端末のファイル選択と共有でJSONを書き出し・復元できる。教材・履歴・ブックマーク・設定を含み、暗号化はしない。復元前に検証し、現在データへの置換はユーザー操作で確認する。Android版はOSの自動バックアップを無効にし、インターネット権限も宣言しない。自動クラウド送信はなく、端末外への保存は共有操作で明示的に行う。
