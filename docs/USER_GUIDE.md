# かなへび学習室 — 初版の使い方

## Androidで始める

インストール用ファイルは `kanahebi-study-0.1.0-arm64.apk`。Pixel 9aなどのarm64 Android向けです。配布APKがある場合はスマホへ保存し、Androidのファイルアプリから開きます。Androidが求めた場合に限り、そのファイルを開くアプリからのインストールを許可してください。初版は試用署名で、ストア配布版ではありません。

起動後はアカウント、PC、開発サーバー、初回の教材ダウンロードを使わずに学習する構成です。有機・高分子の教材は同梱しています。実機での確認項目と検証済みの範囲は [RELEASE_VALIDATION.md](RELEASE_VALIDATION.md) を参照してください。

## 学習する

- **ホーム**：次のおすすめと復習数を確認します。
- **コース**：おすすめの知識を読み、問題を解きます。前提知識は案内だけで、先の単元も開けます。既習範囲は単元の3〜5問で確認できます。
- **自由学習**：単元、知識、問題形式、難易度、問題数を選びます。学習記録は既定ON。OFFで始めた回答は今回の学習中だけ使い、終了後の履歴・復習・習熟度には反映しません。
- **復習**：期限の来た知識や、想起できなかった知識を確認します。
- **その他**：反応マップ、資料集、総合演習、成績・履歴、ブックマーク、教材とバックアップがあります。

思い出せないときは「わからない」を押し、ヒントか答えと解説へ進みます。ヒントを使って正答しても、最初に思い出せなかったことは無補助の正答へ置き換えません。数値回答は単位を付けずに入力します。名称や式の回答は教材が定義した別表記も受け付けます。

記録ONの確定した回答はその場で保存されます。途中で終了しても残ります。未回答と記録OFFの結果は終了時に残りません。OSがアプリを終了した場合、学習中の問題位置は再開せず、保存済みの履歴から次の学習を選び直します。

## 教材を追加する

開発者が用意した `.study-pack.json` をスマホへ保存し、「その他 → 教材パック・データ → 専用教材パックを追加・更新」で選びます。追加後は「この教材に切り替える」を押します。PDFやウェブページを直接教材へ変換する機能はありません。

`math-check.study-pack.json` は別教科で同じアプリを動かすための一次方程式3問の確認用教材です。数学全体の教材ではありません。

## データを守る

「バックアップを書き出す」で教材・解答履歴・ブックマーク・設定をJSONに保存できます。復元は現在のデータを置き換えるので、必要な現在データを先に書き出してください。初版は自動同期や暗号化を行いません。

アプリ削除やAndroid設定でのデータ消去に備え、バックアップはアプリの外へ保存してください。ブラウザで確認したデータとAndroidアプリのデータは別です。

## 教材の位置付け

13単元、114知識、185問、18反応関係を収録した導入・基本演習の初版です。難関大学向けの演習を十分な量まで揃えた完成教材ではありません。習熟度の表示も暫定的な目安で、正答率や合格可能性を表すものではありません。
