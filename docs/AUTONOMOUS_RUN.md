# Autonomous first-release work contract

Date: 2026-10-06 JST. This records execution policy and acceptance criteria; current progress belongs only in `STATUS.md`.

## Authorized scope

Continue ordinary research, design, implementation, installation of required build tools, meaningful testing and GitHub checkpoint commits without waiting at each step. Android is the first distribution target for the user's Pixel 9a; retain an Expo/TypeScript architecture and a generic subject-independent learning engine. No paid service, account creation, remote publishing or user-device operation is required.

## Milestones

1. Reconcile repository, record this run in STATUS, research official curriculum and firsthand teaching/development practice.
2. Define the full organic/polymer curriculum and a generic pack/evidence contract. Separate prerequisite recommendations from access permissions.
3. Implement Stage 0 as a working offline vertical slice. Prove grading, unknown/hints, tracked versus ephemeral free study, persisted progress and review.
4. Extend lessons and original exercises across hydrocarbons, oxygen-containing compounds, aromatics, natural compounds, polymers and integrated skills. Do not equate topic coverage with sufficient advanced-exam practice density.
5. Add reference, reaction relationships, progress, local pack installation/update and a tiny non-chemistry pack to test extensibility.
6. Produce and validate an available standalone distribution. Keep reproducible build instructions and distinguish compiled outputs from untested device behavior.

## Release acceptance gates

- App starts without an account or running development server.
- Bundled lessons/questions/explanations are present at installation; no first-launch download is necessary.
- Five main destinations work on a portrait phone layout.
- Guided recommendations use learner evidence; no topic is hard-locked.
- Free selection supports unit, concept, format and difficulty. Recording defaults to ON and the session policy is immutable once started.
- Recording OFF does not insert sessions, attempts, evidence, mastery, misconceptions, review schedules or guided progress. Only ephemeral results and explicit non-grade actions may persist.
- Unknown remains unknown evidence even after hint-assisted success. It does not generate an invented wrong-choice misconception.
- Selection answers have a visible unknown action; invalid numeric/text answers do not create failed-recall evidence.
- Correct answers, staged hints and full explanations exist for every shipped question. No runtime unconstrained AI question generation.
- Stable IDs, schema/capability checks, reference validation and atomic pack updates preserve learner history.
- Review is scheduled locally; overdue items are accessible offline.
- Core learner functions work after process restart and with network disabled.
- Data-loss boundaries and known limitations are documented accurately.

## Decisions when blocked

- Use pinned stable package versions from the installed Expo release, not an unverified beta.
- Prefer a local Android build; do not spend money or create an EAS account. If native compilation is blocked, preserve tested source and a local browser verification path; explicitly report the APK gate as incomplete.
- Research does not delay the vertical slice indefinitely. Preserve sources and implement deterministic, inspectable rules before sophisticated modeling.
- Do not fabricate a successful test, installed APK, advanced-question completeness or ongoing background run.
- Commit self-contained milestones so interruption loses little work. Push/connector sync must be confirmed; a local commit alone is not remote persistence.
- On stop, record exact last successful commands, remaining gates and the next executable step in STATUS. Do not create a competing checkpoint file.

## Deferred scope

AI chat, cloud sync, third-party markets, arbitrary external data conversion in the app, molecular freehand editing and empirically calibrated personalization are not first-release blockers. Keep architectural extension points and mark absent capabilities honestly.
