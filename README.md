# kanahebi Study App

基礎確認から難関大学入試レベルまで、学習者の状態に合わせて学びながら、必要な範囲を自由にも演習できる local-first 学習アプリ。

初期コンテンツは **大学受験レベルの有機化学・高分子**。まずこの範囲を実用レベルまで完成させる一方、アプリ本体は特定科目へ固定せず、将来的に化学の他範囲や他教科を教材パックとして追加・インポートできる構造にする。

## Core learning experiences

### コース学習 (Guided Course)

学習者の知識状態・誤答傾向・ヒント使用・忘却状況などをもとに、次に学ぶ内容や復習内容を個人最適化する。

基礎確認 → 学習 → 演習 → 応用 → 入試レベル → 復習を連続した学習ルートとして扱う。

### 自由学習 (Free Study)

単元・知識・問題形式・難易度などから、自分で自由に選んで学習・演習する。

既定では自由学習の結果も共通の学習モデルへ反映し、習熟度・弱点・復習予定の改善に利用する。

必要な場合は **「学習記録に反映しない」** 状態へ切り替えられる。この状態では自由に問題や教材を試せるが、個人最適化用の習熟度・弱点判定・復習スケジュールを変更しない。

コース学習と自由学習は同格の主要機能とし、どちらか一方に依存しない。

## Product principles

### Offline-first

学習の中核機能はネット接続なしで動作する。

- 教材・問題・標準解説・段階ヒント
- コース学習の進行
- 自由学習
- 採点
- 進捗・誤答・弱点記録
- 復習スケジューリング
- 反応マップ等の教材固有ビュー
- ローカル検索

AIによる追加解説、クラウド同期、コンテンツ更新などのオンライン機能は任意の追加層とし、利用不能でも学習を継続できる設計にする。

### Smartphone-first / standalone

学習者はスマートフォン1台だけで全学習機能を利用できることを必須とする。
PCや常時接続サーバーを要求しない。

UIはスマートフォン縦画面を第一対象に設計し、タップ操作、数式・構造式の視認性、短時間学習と長時間演習の両方を考慮する。

### Extensible / content-pack based

アプリ本体を汎用の学習エンジンとして保ち、教材をバージョン管理された Content Pack として分離する。

- 問題・教材をアプリ本体から分離
- カリキュラム／知識ノードをデータ駆動化
- 問題形式を追加可能にする
- 学習アルゴリズムを交換・改良可能にする
- Content Pack の追加・更新・インポートを可能にする
- 初期の有機・高分子以外の化学分野を追加可能にする
- 将来的な数学など他教科の追加を阻害しない
- 開発者が作成・検証した専用 Content Pack を宣言的データとして扱い、任意コードを実行しない

新しい教材は既存の問題・表示能力を利用して追加できる。まったく新しい入力方式や教材固有UIが必要な場合は、アプリ本体側へ新しい capability を追加する。

  - 構造決定
  - 合成経路

  - 合成高分子
  - 天然高分子

## Answer UX principle

選択式問題には **「わからない」** を回答手段として用意する。

「わからない」は通常の誤答や誤選択とは区別し、知識の想起失敗／未定着の証拠として扱う。無理な当てずっぽうを促さず、適切なヒント・解説・復習へつなげる。

- ホーム

- 自由学習

- その他

## Technical direction

現時点の第一候補：

- React Native + Expo
- TypeScript
- SQLite を端末内の学習データ正本として利用
- local-first / offline-first architecture
- オンライン機能は optional service として分離
- 教材データとユーザー学習データを分離
- versioned Content Pack + capability based architecture

## Confirmed decisions — 2026-10-06 handoff

- コース学習は原則ロックなし。前提不足は推奨として提示し、本人が望めば先へ進める。
- 自由学習は記録ONが既定。OFFでは採点・解説・一時集計を利用できるが、終了後に解答履歴・習熟度・弱点・復習予定・コース進捗を残さない。ブックマークなど成績と無関係な明示操作は保存する。
- 「わからない」の後は「ヒントを見る」「答えと解説を見る」に分岐する。最初の想起失敗とヒント後の成功を別の証拠として扱い、無補助の正解に上書きしない。
- 既習範囲は3〜5問程度の理解度チェックでスキップできる。自己申告だけで習得済みにしない。通過を恒久的習得の証明とは扱わず、以後の証拠で更新する。
- 教材は開発者であるアシスタントがアプリ専用の自作Content Packへ整える。ネット上の問題・資料やユーザー提供素材を分析し、解答、詳細解説、段階ヒント、必要知識ノード、誤答分類、出典情報を付与して検証する。
- 外部の生データ・任意形式・他人製パックをアプリへ直接投入する機能は想定しない。アプリが受け取るのは開発者が用意した対応形式のパックのみ。スマホでの専用パック追加・更新と他教科への拡張は維持する。
- アプリ内のAI教材パッケージング、自動スクレイピング、公開第三者パック市場、汎用外部形式変換は現スコープ外。無料AIによる変換も今回実装しない。
- 自作への変換は出典や利用条件を消すことではない。素材の出典・利用条件・改変内容を記録し、再配布可能性を確認して教材化する。
