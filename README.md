# kanahebi Study App

大学受験レベルの有機化学・高分子を、基礎確認から難関大レベルまで一貫して学習するための学習アプリ。

## Core concept

本アプリは、次の2系統の学習体験を両立する。

1. **Story Mode**
   - 学習者の知識状態・誤答傾向・ヒント使用・忘却状況などをもとに、次に学ぶ内容を個人最適化する。
   - 基礎確認 → 学習 → 演習 → 応用 → 入試レベル → 復習を自動的につなぐ。

2. **Free Mode**
   - 単元一覧・知識一覧・問題形式・難易度などから、自分で自由に選んで学習・演習する。
   - 知識確認、特定単元の集中演習、反応マップ参照、模試形式などを含む。

Story Mode と Free Mode は同格の主要機能とし、どちらか一方に依存しない。

## Product principles

### Offline-first

学習の中核機能はネット接続なしで動作する。

- 教材・問題・標準解説・段階ヒント
- Story Mode の進行
- Free Mode
- 採点
- 進捗・誤答・弱点記録
- 復習スケジューリング
- 反応マップ
- ローカル検索

AIによる追加解説、クラウド同期、コンテンツ更新などのオンライン機能は任意の追加層とし、利用不能でも学習を継続できる設計にする。

### Smartphone-first / standalone

学習者はスマートフォン1台だけで全学習機能を利用できることを必須とする。
PCや常時接続サーバーを要求しない。

UIはスマートフォン縦画面を第一対象に設計し、タップ操作、数式・構造式の視認性、短時間学習と長時間演習の両方を考慮する。

### Extensible

初期実装を有機化学・高分子専用として最適化しつつ、将来の追加を壊さない構造にする。

- 問題・教材をアプリ本体から分離
- カリキュラム／知識ノードをデータ駆動化
- 問題形式を追加可能にする
- 学習アルゴリズムを交換・改良可能にする
- コンテンツパックの追加・更新を可能にする
- 将来的な他科目追加を阻害しない

## Scope

- 有機化学
  - 構造式・官能基・異性体
  - 炭化水素
  - アルコール・エーテル
  - アルデヒド・ケトン
  - カルボン酸・エステル
  - 芳香族化合物
  - 構造決定
  - 合成経路
  - 有機計算
- 天然有機化合物
  - 油脂
  - 糖類
  - アミノ酸・タンパク質
- 高分子化合物
  - 合成高分子
  - 天然高分子

## Technical direction

現時点の第一候補：

- React Native + Expo
- TypeScript
- SQLite を端末内の学習データ正本として利用
- local-first / offline-first architecture
- オンライン機能は optional service として分離
- 教材データとユーザー学習データを分離
