# kanahebi Study App

大学受験レベルの有機化学・高分子を、基礎確認から難関大レベルまで一貫して学習するための学習アプリ。

## Core concept

本アプリは、次の2系統の学習体験を両立する。

1. **Story Mode**
   - 学習者の知識状態・誤答傾向・ヒント使用・忘却状況などをもとに、次に学ぶ内容を個人最適化する。
   - 基礎確認 → 学習 → 演習 → 応用 → 入試レベル → 復習を自動的につなぐ。

2. **Free Mode**
   - 単元一覧・知識一覧・問題形式・難易度などから、自分で自由に選んで学習・演習する。
   - 知識確認、特定単元の集中演習、反応マップ参照、模試形式などを含む。

## Scope

- 有機化学
  - 構造式・官能基・異性体
  - 炭化水素
  - アルコール・エーテル
  - アルデヒド・ケトン
  - カルボン酸・エステル
  - 芳香族化合物
  - 構造決定
  - 合成経路
  - 有機計算
- 天然有機化合物
  - 油脂
  - 糖類
  - アミノ酸・タンパク質
- 高分子化合物
  - 合成高分子
  - 天然高分子

現在地点は `STATUS.md` を唯一の正本とする。
詳細仕様は `docs/PRODUCT_SPEC.md` にまとめる。
